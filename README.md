# PythonNetworkFilter

Educational Python project for network log analysis, device configuration validation, and basic firewall security monitoring.

## Overview

This project contains **five practical Python exercises** focused on networking, cybersecurity fundamentals, file processing, and basic log analysis.

The scripts read network-related files, process information, detect specific events, and generate simple reports.

---

## Features

### 1. Network Connection Analysis

**Script:** `task1.py`

- Reads connection events from `network.log`
- Identifies unique IP addresses
- Counts `CONNECT` events for each IP address
- Saves results to `connections.txt`

### 2. Network Configuration Validation

**Script:** `task2.py`

- Reads device settings from `network_config.txt`
- Extracts hostname, IP address, subnet mask, gateway, and DNS
- Checks whether devices belong to the `192.168.1.0/24` network
- Generates `devices.txt`

### 3. Firewall Log Analysis

**Script:** `task3.py`

- Reads firewall events from `firewall.log`
- Counts `ALLOW` and `DENY` events
- Identifies IP addresses with three or more `DENY` events
- Saves flagged addresses to `blocked.txt`
- Generates statistics in `report.txt`

### 4. Network Equipment CSV Report

**Script:** `task4_csv_report.py`

- Reads device information from `network.csv`
- Counts devices with `Online` and `Offline` status
- Identifies offline devices
- Saves device names and IP addresses to `offline_devices.txt`

### 5. Authentication Log Analysis

**Script:** `task5_auth_log.py`

- Reads authentication attempts from `auth.log`
- Counts failed login attempts for each IP address
- Identifies addresses with three or more failed attempts
- Saves suspicious addresses to `suspicious_ips.txt`

---


## How to Run

Install Python 3 and execute the scripts from the project directory:

```bash
python task1.py
python task2.py
python task3.py
```

No external Python libraries are required for the basic exercises.

## Educational Purpose

This project was created as part of hands-on Python and networking studies.

It demonstrates file handling, dictionaries, loops, conditional statements, log parsing, and basic security monitoring concepts.

The project uses simulated network data and is intended for educational purposes only.

## Sample Output Files

The repository also includes example reports generated by the scripts:

- `connections.txt` — connection statistics
- `devices.txt` — processed network device information
- `blocked.txt` — IP addresses flagged by firewall analysis
- `report.txt` — firewall event statistics
- `offline_devices.txt` — devices currently marked as offline
- `suspicious_ips.txt` — IP addresses with repeated failed login attempts
